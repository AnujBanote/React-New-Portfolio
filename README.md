# 🌐 Personal React Portfolio – Anuj Banote

This is my **personal portfolio website** built using **React.js**, showcasing my projects, skills, and contact information.  
It features **dark/light theme toggle**, **animated hover effects**, and a **working contact form**.

---

## 🚀 Live Demo

👉 [View Live Portfolio](https://your-portfolio-link.vercel.app)

---

### 🏠 Hero Section

- Interactive **Theme Toggle** (Light/Dark mode)
- Responsive profile section with social icons
- Resume download button

### 💼 Projects Section

- Displays featured React projects
- Hover animations for project cards
- Each project has a name, description, and unique image

### ⚙️ Skills Section

- Categorized technical and soft skills
- Fully responsive grid layout

### ✉️ Contact Section

- Simple form for users to reach out
- Includes fields for **Name**, **Email**, and **Message**
- Submit button with hover animation
